## PROJETS OPEN SOURCE — GITHUB

### [delphi-logging-facade](https://github.com/pleali/delphi-logging-facade)
**Facade de logging inspirée de SLF4J pour Delphi**
- Architecture interface-based découplant le code applicatif des implémentations
- Loggers hiérarchiques style SLF4J/Logback avec `TLoggerFactory`
- Configuration externe (fichiers properties) avec wildcards et hot-reload
- Adapters LoggerPro et QuickLogger
- Thread-safe, optimisé performance, stack traces avec JCL Debug

### [delphi-mqtt-client](https://github.com/pleali/delphi-mqtt-client)
**Client MQTT natif pour Delphi**
- Protocole MQTT pour IoT et messagerie asynchrone
- Support des QoS levels et reconnexion automatique

### [jsonrpc-mqtt](https://github.com/pleali/jsonrpc-mqtt)
**Framework JSON-RPC 2.0 over MQTT — Java + client Delphi**
- Communication peer-to-peer entre nodes distribués (IoT, microservices, edge computing)
- Interopérabilité Java/Delphi via protocole standardisé
- Type-safe, async, framework-agnostic
